# 人生往后推 · 设计说明

本文回答五件事：基线 `4a5b88cc` 能不能做到想要的体验；玩法怎么设计；开局、年度主界面、重大抉择、财务、双线结局、重玩六个桌面画面的状态与优先级；怎样接进开图；和 1in8b 比该学什么、不该照搬什么。最后列出需要你拍板的问题。

想要的体验，按你的原话整理：输入开图资料，用 Remake 的代码模拟一段人生；你调整投资、工作、生活、家庭、居住方向的计划，决定买不买车、买不买房、要不要去远方、要不要旅游、要不要买医疗保险；像《模拟人生》，参考 1in8b 的信息组织；加上你设计好的六个科幻未来世界结局。

## 1. 审阅：基线能做到吗

**结论：引擎骨架是对的，值得保留；玩法层、钱、时间和数据层撑不起这个体验，需要重写。** 这次保留骨架、重写上面几层，没有推倒引擎。

保留的骨架：

- Remake 的条件 DSL 与加权抽取（`vendor/remake`），事件按处境筛选、加权、冷却。
- 有地址的确定性抽样 `sample(seed, year, category)`：两条线、同龄人、重玩共用同一个世界，抽样不会因为分支多抽一次而错位。
- 存档是命令日志，载入时校验后重放，不恢复任意状态。
- 基线（照现在过）与玩家线同处一个世界。
- 整数分账本和逐年核对。

基线里撑不住的地方，以及这次怎么改：

| 基线 | 问题 | 现在 |

| 12 年切片 | 一段人生太短 | 10 / 20 / 30 年，从当前年份开始 |

## 2. 玩法设计

### 核心循环

**定计划 → 时间流动（事件按月出现）→ 门槛停表、你来选 → 年末结算 → 改计划。** 一年约 45 秒，可 2×、4×。“到下个抉择”直接跳到下一次停表。

### 七条线

工作、钱、居住、家庭、健康、远方、世界。每条线有计划（长期执行的规则）和抉择（门槛时刻的一次选择）。左栏“计划”卡按这七条线写出现在在执行什么。

| 线 | 计划 | 抉择 |
| --- | --- | --- |
| 工作 | 每两年看机会、每两年职训；下一年重心 | 每五年一次职业岔路（转职、创业、出国、投资、读书、自定义的那件事）；平行世界里的工作转折 |
| 钱 | 每月定投；指数一年跌超 15% 时的规则（问我 / 不动 / 加仓 / 卖出） | 规则为“问我”时，指数大跌后停下来问 |
| 居住 | — | 买房：继续租 / 在城里买 / 回老家买并换工作，再选首付和年限 |
| 家庭 | 父母 60 岁后每年给多少 | 结婚或同居；要不要孩子；父母住院后谁来照顾 |
| 健康 | 运动习惯 | 医疗险 / 重疾险 |
| 远方 | 不出远门 / 每年短途 / 每年一次远行 | 买不买车；三个月远行或外派一年 |
| 世界 | — | 隐藏世界里的桥接与口述记录 |

### 抉择什么时候出现

| 抉择 | 条件（游戏设定） |
| --- | --- |
| 保险 | 第二年起，没有医疗险，60 岁以下；只问一次 |
| 买房 | 第三年起，租房或住家里，55 岁以下，首付两成加税费买得起（城里或老家）；一直选“继续租”会隔 4、8、12 年再问 |
| 买车 | 第四年起，没有车，存款够 6 万；只问一次 |
| 结婚 / 同居 | 恋爱满两年，55 岁以下；一直选“维持现状”会隔 3、6、9 年再问 |
| 孩子 | 婚后一年起，43 岁以下，还没有孩子；一直选“再说”会隔 3、6 年再问 |
| 父母 | 年长的一位 68 岁那年住院，需要人照看三个月；只问一次 |
| 指数大跌 | 规则为“问我”，去年跌超 15%，手里有股票；一直选“不动”会隔 4、6 年再问 |
| 远行 / 外派 | 第六年起，55 岁以下，存款够 8 万；只问一次 |
| 职业岔路 | 每五年一次 |
| 世界里的工作转折 | 现实线 2031 年起、平行世界 2036 年起，在职；按所在世界给出不同选项 |
| 桥接 | 平行世界、隐藏链解锁、战争结束的下一年 |

一年最多停两次，其余顺延到下一年。卡片只写当下算得清的成本和直接效果（首付、月供、利息合计、保费），不预告结果；“照现在过”会选哪一项标在卡上。

### 两条线与归因

基线是同一个人每次都“照现在过”、不改计划；玩家线是你。两条线用同一个世界种子，行情、世界新闻、共同冲击完全相同，所以差别只来自你的选择和计划。结局逐步归因：把某一步换回“照现在过”、其余不变，重放整局，比较终点的净资产和四种状态。

### 世界

现实线：世界按现在的统计缓慢变化，不分叉，不出现隐藏世界。

平行世界：AI、自动化、不平等、企业权力、地缘压力五个变量按种子随机游走；2035 年按阈值转向六个世界之一（你的设计稿 v4 清单），每个世界约 14–21% 的种子。分叉后是科幻推演，有自己的新闻、行情修正和工作转折。隐藏世界（人机融合）由五个独立的布尔量决定（接触 5%、高阶 AI 70%、机器人 70%、战争 60%、人类胜利 70%，联合约 1.03%），解锁后出现桥接抉择和两种隐藏结局；拒绝不扣分。玩家选择永远不改变世界。

### 内容与语气

- 日常事件约 150 个：通用事件，加上按处境筛选的事件（城市 / 老家、租 / 买、伴侣、孩子的年龄段、父母的年龄、车、在职 / 创业 / 学生 / 待业 / 退休、海外、六个世界各自的日常）。同样的回答下，两个种子“发生在你身上的事”平均重合不到一半。
- 生病、失业、再就业、退休、父母住院、欠款都有规则和来源说明；主角不会死亡，疾病只写一行，不描写过程。敏感事件附求助链接。
- 不打分，不给人生总评，不做预测。结局最后一张卡固定是“故事在这里存档，不是在这里定论”。
- 界面不写说明行和安抚句，只放内容、状态和操作（照开图 `AGENTS.md` 第 11 条）。统计来源跟着数字走；规则、参数和来源集中在“规则、参数与来源”抽屉里。

## 4. 怎样接进开图

1. **入口**：开图“资料”里加“导出推演资料包”；“问问”可以用游戏里的同一份提示词让 AI 生成角色卡。游戏导入页已经能读这两种。
2. **资料包就是角色卡 version 2**：`life` 部分只放处境和档位——城市、老家、住房、伴侣、孩子个数、父母年龄段、收入档、存款档、保险、最多三个目标。不放具体金额、账户、单位、地址，不放伴侣、孩子、父母的名字和健康。
3. **单向**：游戏只读资料包，永远不写回开图的事实。游戏里得出的东西（例如“每月定投 ¥1,000 的那条线多了 ¥40 万”）只能作为建议回到开图，由你采纳后才变成计划或待办。
4. **隐私**：网页不联网、不上传；对照卡不含个人文字；存档只在你主动下载时生成。
5. **数据规范**：按开图的约定，改 PRD §6 数据规范前要先和你确认。建议不改规范，只加一份“推演资料包”导出，字段沿用这里的角色卡格式。

## 5. 和 1in8b 比

1in8b 用联合国的人口与经济数据，按真实人口比例让你“生”为八十亿人中的一个，人生事件按统计发生。它做得好的地方：真实数据决定“你可能是谁”；事件旁边有数据；按时间顺序讲；一局很短；分享卡好看。

**可以学的思路**，这次都用上了：统计驱动、每条数字标来源和口径、时刻告诉你在分布里的位置、按时间顺序叙述、一局有清楚的结束和分享卡。

**不能直接照搬的**：它的代码、文案、图片和具体数值没有许可，不能拷贝；联合国、世界银行的数据本身是公开的，可以从原始来源直接取用并注明，但对中国玩家，国家统计局、卫健委、民政部的口径更准，这次用的是这些。

**可以改进的地方**：

- 它从“随机出生”开始，我们从**你自己**开始（开图资料）。
- 它的事件按人口比例发生，个人做不了什么；我们有计划和抉择，并且在同一个世界里给出“照现在过”的对照和逐步归因。
- 它的数字是国家平均；我们的钱按真实的工资单、房贷、公积金规则逐年记账，城市分五类。
- 全国比率从不冒充你的个人概率；所有游戏设定在规则抽屉里公开。
- 平行世界的科幻部分和现实统计分开标注。

## 6. 数据来源与游戏设定

公开统计（`src/stats.ts`）：国家统计局 2025 年居民收入和消费支出（五等份、中位数）、2025 年城镇单位平均工资、2025 年国民经济运行解读（失业率）；国家卫健委 2024 年卫生健康统计公报（预期寿命）；民政部 2024 年民政事业统计公报（婚姻登记）；公安部 2024 年机动车保有量；全国银行间同业拆借中心贷款市场报价利率；《个人所得税法》及 2023 年 8 月起的专项附加扣除标准。

游戏设定（在规则抽屉里全部可见）：五类城市的房租、房价、面积、生活费、工资倍数、养孩子和交通费用；行情均值、波动和衰退概率；住院、失业、再就业的概率，退休年龄和养老金比例；保险保费；首套房贷利率 3.1%；世界变量的漂移和阈值；隐藏链概率和时间表。

## 8. 需要你确认的问题

1. **隐藏世界的时间表提前了。** 设计稿 v5 是接触 2036–2055 年、AI 与机器人门槛 2038–2058 年、战争 2060–2070 年开始并持续 2–5 年；从 2026 年开始的 30 年一局到 2055 年就结束，战争还没开始，隐藏结局永远遇不到。现在是接触 2036–2042 年，AI 和机器人在接触后第一、二年，战争 2040–2047 年开始，持续 2–4 年。概率没改。
2. 旧的 version 2 存档规则不同，不能原样重放，现在提示重新开局。
3. 计划一律从下一年起生效；左右两栏在年末结算后才更新，不提前泄露这一年的结果。
4. 一年最多停两次抉择，其余顺延。
5. 原 README 写“继续须重新计一个完整年度间隔”；现在是保留进度、至少留四分之一年，并且不收回已经出现的内容。
6. 城市价格、工资倍数、各种概率都是游戏设定，已在规则里标明；要不要换成有来源的数据由你定优先级。
7. 开图侧要不要做“推演资料包”导出、放在哪个入口。
